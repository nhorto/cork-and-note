# Cork & Note ad concept studio

Open [index.html](index.html) directly in a modern browser. Everything needed by the gallery is embedded, including the existing brand image and wine-entry screenshot. No server, build, internet connection, or account is required.

[View the static overview](overview.png) to see all six concepts without running the gallery.

The gallery includes six concepts, Facebook/Instagram preview framing, portrait feed (4:5), square (1:1), and Story (9:16) compositions, plus before-launch and app-available copy. These are illustrative placement previews rather than exact Ads Manager reproductions.

Mark concepts Keep, Explore, or Pass and write notes. In Mix & match, combine a message, visual, palette, and AI emphasis; edit the headline; and save combinations. **Download my feedback** exports notes and saved combinations to a text file. The mixer also downloads draft PNG artwork and a brief for a later image-generation round.

Choices are stored in the current browser when local storage is available. A copy in another folder or browser may have separate storage. Export feedback before moving between copies. When storage is unavailable, the gallery remains usable and displays a reminder to download feedback.

Images generated for final advertisements are intentionally deferred until the owner selects directions. The artwork here uses original SVG illustrations and existing repository assets. A02 contains a clearly identified scripted conversation. A05 uses the existing `site/assets/shot-2-log-a-tasting.png`; it is not a newly invented interface. Other notes and scenes are illustrative and imply no customer testimonial or winery endorsement.

For the campaign strategy, copy, budget scenarios, measurement, and production handoff, see [the campaign plan](../../docs/marketing/ad-campaign-plan-2026-09-09.md). For broader messaging and product-claim findings, see [the positioning report](../../docs/marketing/positioning-and-messaging-report-2026-09-09.md).

The gallery contains inline CSS and JavaScript, with two embedded data URLs near the start of the script. `CONCEPTS` holds the copy and image briefs; `PALETTES` holds colors; `artFor` draws each visual direction; `creativeSvg` composes the selected placement. No app or production-site code imports this directory.
