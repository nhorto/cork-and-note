# Cork & Note — The Wine Ampersand

Open `index.html` to compare three original AI-generated PNG logo concepts:

- A: an ampersand whose lower loop becomes a stemmed wine glass.
- B: a wine-glass silhouette with an ampersand in its negative space.
- C: a flowing calligraphic ampersand that suggests the glass through its loops and stem.

All three were generated with the built-in image-generation tool using the approved
Bordeaux square / gold-ring C & N image from Round 02 as an edit reference. The
generation prompts are saved in `PROMPTS.md`. The original output pixels are
preserved in `images/`; these are not rasterized SVG substitutes.

Select a concept to preview that same generated image at phone-icon sizes and in
illustrative login, store-listing, and phone home-screen placements. The full-size
square artwork is kept intact; rounded corners are CSS-only preview treatments.

The gallery supports local notes, downloadable feedback, and original PNG downloads.
It works offline from the folder without a server. This collection is also linked
and pictured at the top of the Round 02 HTML gallery.

These are review concepts; production app artwork has not been replaced.
